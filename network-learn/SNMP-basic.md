# SNMP 개념

## 1. SNMP 란
>SNMP(Simple Network Management Protocol)는 네트워크 장비의 상태를 원격으로 조회하고, 장비에 이상이 생기면 알림을 받기 위한 표준 프로토콜. 라우터, 스위치, 서버, NVR, UPS 같은 장비들이 같은 방식으로 관리될 수 있도록 만든 공통 규격임.

### 구성 요소

|구성 요소|역할|예시|
|-|-|-|
|Manager|장비에 상태를 묻고, 알림을 받는 쪽|미니PC나 중앙 관제 서버|
|Agent|장비 안에서 요청에 답하는 프로그램|NVR 내부의 SNMP 기능|
|MIB|장비가 제공하는 항목의 목록이자 사전|표준 MIB와 한화 전용 MIB|
|OID|MIB 안의 각 항목에 붙은 숫자 주소|예: `1.3.6.1.2.1.1.3.0`은 가동 시간(sysUpTime)|

### 동작 방식

|동작|방향|설명|
|-|-|-|
|GET/GETNEXT/GETBULK|Manager $\rarr$ Agent|값 조회. GETBULK는 어려 값을 한 번에 가져옴 (v2c 이상)|
|SET|Manaer $\rarr$ Agent|값 변경. 장비가 쓰기를 허용하는 항목만 가능|
|TRAP/INFORM|Agent $\rarr$ Manager|이벤트가 생기면 장비가 먼저 알림. INFORM은 수신 확인까지 받음|


### 포트
- UDP 161: 조회와 설정 요청을 받는 포트
- UDP 162: Manager가 Trap을 받는 포트

### 버전별 차이

|버전|인증 방식|암호화|비고|
|-|-|-|-|
|v1|커뮤니티 문자열(평문)|없음|오래된 방식|
|v2c|커뮤니티 문자열(평문)|없음|가장 널리 쓰임. GETBULK 지원|
|v3|사용자 계정 기반|지원|현장 운용에 권장. authPriv 모드(인증+암호화) 사용|

## 2. SNMP로 할 수 있는 일
### 모니터링
|항목|출처|활용|
|-|-|-|
|장비가 응답하는지 여부, 가동 시간|표준 MIB-II|가동 시간이 갑자기 줄었다면 예기치 않은 재부팅이 있었다는 뜻|
|장치명, 설치 위치, 펌웨어 정보|표준 MIB-II|여러 현장의 장비 목록 관리|
|네트워크 인터페이스 상태, 송수신 트래픽|표준 IF-MIB|카메라 영상 유입이 끊겼는지 간접 확인|
|HDD 상태, 녹화 상태, 영상 끊김, 팬, 온도 등|한화 전용 MIB(모델별 다름)|녹화 장애를 조기에 감지|
|이벤트 Trap|장비 설정|HDD 고장, 디스크 가득 참, 영상 끊김, 재부팅 같은 이번테를 즉시 통보|

### 기대하기 어려운 일(제어)
- 재부팅이나 설정 변경: 표준 MIB에는 재부팅 명령이 없음. 이런 NVR은 SNMP를 보통 읽기 전용 모니터링 용도로 제공함. 전용 MIB에 쓰기 가능한 재부팅 항목이 있는지는 MIB 파일로 확인해야 하나, 이 용도로 기대하지 않는게 나음
